# Contributing to Vision

Thanks for helping! Bug reports, feature ideas and pull requests are all welcome.

## Reporting a bug
Open an issue and include: your Windows version, the Vision version (tray menu → *Run diagnostics* copies a report), what you said or did, what you expected, and what happened. Logs are in the folder opened by the tray menu → *Open log folder*. **Remove your API key and any private information before posting.**

## Suggesting a feature
Open an issue describing what you want to say or do and why. Screenshots or examples help.

## Pull requests
1. Fork the repository and create a branch.
2. Run it with `npm install` then `npm start` on Windows.
3. Keep changes focused, and match the style of the surrounding code.
4. **Safety rules are sensitive.** Changes to `src/main/safety.js` or to the approval logic need a clear explanation of why they are safe.
5. Describe what you changed and how you tested it.

By contributing you agree that your contribution can be distributed under the project's licence.
