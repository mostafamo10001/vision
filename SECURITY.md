# Security

Vision can control a PC, so security issues matter.

**Please do not open a public issue for a vulnerability.** Use GitHub's *Report a vulnerability* button on the Security tab of this repository, or contact the maintainer privately. Include the steps to reproduce, the Vision version, and the impact you see.

Examples of what to report: a way to run commands without the approval prompt, a way to bypass the command blocklist or protected paths, reading or leaking the stored API key, or a way for text on a web page or in a file to make Vision act against the user's wishes.
